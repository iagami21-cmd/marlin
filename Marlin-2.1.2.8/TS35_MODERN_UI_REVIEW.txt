TS35 MODERN UI - REVISÃO COMPLETA
Marlin 2.1.2.8 / MKS Monster8 V2.0 / MKS TS35 V2.0

Correções aplicadas nesta versão:

1. Navegação das telas
   - Botões que abrem telas agora usam MENU_SCREEN.
   - Botões de comando continuam usando BUTTON.
   - Isso evita que draw_status_screen() redesenhe a Home imediatamente.

2. Geometria da Home 480x320
   - Home usa 3x3 cards de 104x84.
   - Cards ocupam Y=52..312.
   - Painel de telemetria ocupa Y=52..312.
   - A área de 320x480 é preenchida pelo canvas.

3. Ícones
   - Foram criadas versões 32x32 4bpp dos ícones usados na Home e nos cabeçalhos.
   - Ícones 64x64 não são mais colocados em cards de 104x84.
   - Isso elimina a sobreposição ícone/texto.

4. TFT / fila gráfica
   - A UI personalizada usa canvas + tarefas da fila TFT.
   - Não usa tft.fill() na UI personalizada.
   - tft.fill() existente fora da UI personalizada permanece inalterado.

5. Touch
   - HOME e botões de navegação usam MENU_SCREEN.
   - Comandos de movimento, fan, extrusão, pausa etc. usam BUTTON.
   - BACK continua usando o controle nativo BACK.

6. Compatibilidade Marlin 2.1.2.8
   - M25_STR removido; pausa usa queue.inject(F("M25")).
   - tft.add_text() recebe TFT_String.
   - Nenhuma pasta assets é necessária para TFT_COLOR_UI.

7. Auditoria estrutural
   - Chaves balanceadas: 107 / 107
   - Parênteses balanceados: 1026 / 1026
   - M25_STR: 0 ocorrências
   - tft.fill() na UI personalizada: 0 ocorrências
   - Novos ícones 32x32: 512 bytes cada

Limitação:
   O toolchain STM32/PlatformIO do ambiente de revisão não está instalado.
   Portanto esta revisão foi feita estaticamente sobre o código Marlin 2.1.2.8;
   o build físico precisa continuar sendo feito pelo PlatformIO do usuário.
